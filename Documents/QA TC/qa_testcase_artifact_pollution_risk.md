# 오염된 프로세스 (유물, 리스크 효과) QA 테스트 케이스 제공 문서
## 3. 오염된 프로세스: 리스크 효과

### 과부하 코어

1.  **기획 의도**
    - 공격력 페널티 부여 ('정화' 대상)
2.  **핵심 수치 (기획값)**
    - 분류 : 오염된 프로세스 - 리스크 효과 (공격 계열)
    - 오염도 수치 : 10
    - 효과 : 기본 공격력이 20% 감소합니다.
    - 정화 시 변경될 프로세스 : 안정화된 에너지 코어
    - 제한 : 장착 즉시 적용. 정화 시 효과 즉시 제거.
3.  **시나리오**
    - 유물 미장착 상태에서 기본 데미지(값 A), 총 오염도(값 B), HUD 상태 확인 후 검증을 시작한다.
4.  **QA 검증 기준**
    - TC 1 : 유물 장착
    - TC 2 : 유물 해제
    - TC 3 : [장착 검증] 데미지 (A * 0.8), 오염 (B+10), HUD 아이콘 표시 확인
    - TC 4 : [해제 검증] 데미지(A), 오염(B), HUD 복구 확인
    - TC 5 : [정화] 본 유물 정화 시도
5.  **예상 결과**
    - TC 1 : 유물 장착 됨
    - TC 2 : 유물이 정상적으로 해제됨
    - TC 3 : 데미지 20% 감소, 오염 10 증가, HUD 표시됨
    - TC 4 : 데미지, 오염도 원복, 아이콘 삭제됨
    - TC 5 : 유물이 '안정화된 에너지 코어'로 변경되고 페널티 즉시 제거됨
