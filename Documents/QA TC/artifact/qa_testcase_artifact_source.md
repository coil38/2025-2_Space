# 근원 프로세스 (유물) QA 테스트 케이스 제공 문서
## 근원 프로세스
**참고 : 정화된 유물은 오염도 수치가 없습니다.**

## 5. 근원 프로세스

(참고: 근원 프로세스 유물은 오염도 수치가 없습니다.)

### 이중 나선 증폭기

1.  **기획 의도**
    - 최상위 공격 유물 (확률적 추가 타격)
2.  **핵심 수치 (기획값)**
    - 분류 : 근원 프로세스 (공격 계열)
    - 오염도 수치 : 0
    - 효과 : "모든 공격이 15% 확률로 데미지가 1번 더 적용됩니다. (다단히트 각 타격마다 개별 적용)"
3.  **시나리오**
    - 유물 획득 후 HUD 상태 확인 후 검증을 시작한다.
4.  **QA 검증 기준**
    - TC 1 : 유물 장착
    - TC 2 : 유물 해제
    - TC 3 : [장착 검증] HUD 아이콘 표시 확인
    - TC 4 : [조건부 검증] '허수아비' 100회 타격 (단타)
    - TC 5 : [조건부 검증] '허수아비' 100회 타격 (다단히트 스킬)
    - TC 6 : [해제 검증] 효과 즉시 제거, HUD 아이콘 복구 확인
5.  **예상 결과**
    - TC 1 : 유물 장착 됨
    - TC 2 : 유물이 정상적으로 해제됨
    - TC 3 : 아이콘 생성됨
    - TC 4 : 약 15회 데미지 2번 적용됨
    - TC 5 : 각 타격마다 15% 확률 개별 적용됨
    - TC 6 : 효과 제거, 아이콘 삭제됨

### 약점 분석 모듈 (근원)

1.  **기획 의도**
    - 최상위 공격 유물 (지속 공격 시 피해량 증가 버프)
2.  **핵심 수치 (기획값)**
    - 분류 : 근원 프로세스 (공격 계열)
    - 오염도 수치 : 0
    - 효과 : 적에게 10회 공격을 적중시킬 때마다, 10초간 피해량이 10% 증가하는 '분석 완료' 상태가 됩니다. (중첩 2번)
3.  **시나리오**
    - 유물 획득 후 HUD 상태 확인 후 검증을 시작한다.
4.  **QA 검증 기준**
    - TC 1 : 유물 장착
    - TC 2 : 유물 해제
    - TC 3 : [장착 검증] HUD 아이콘 표시 확인
    - TC 4 : [조건부 검증] 몬스터 10회 적중
    - TC 5 : [조건부 검증] (TC 4) 이후 10회 추가 적중 (총 20회)
    - TC 6 : [조건부 검증] (TC 5) 이후 10회 추가 적중 (총 30회)
    - TC 7 : [조건부 검증] (TC 5 상태에서) 5초 경과 후 10회 추가 적중
    - TC 8 : [해제 검증] 효과 즉시 제거, HUD 아이콘 복구 확인
5.  **예상 결과**
    - TC 1 : 유물 장착 됨
    - TC 2 : 유물이 정상적으로 해제됨
    - TC 3 : 아이콘 생성됨
    - TC 4 : '분석 완료' 1스택 (피해 +10%) 10초 발동
    - TC 5 : '분석 완료' 2스택 (피해 +20%) 10초 발동
    - TC 6 : '분석 완료' 2스택, 시간만 10초로 갱신
    - TC 7 : '분석 완료' 2스택, 시간 10초로 갱신
    - TC 8 : 효과 제거, 아이콘 삭제됨

### 과부하 코어 (근원)

1.  **기획 의도**
    - 최상위 공격 유물 (스킬-평타 연계 강화 3회)
2.  **핵심 수치 (기획값)**
    - 분류 : 근원 프로세스 (공격 계열)
    - 오염도 수치 : 0
    - 효과 : 스킬 사용 시 다음 3회의 기본 공격이 강화되어 50% 피해 데미지가 증가합니다.
3.  **시나리오**
    - 유물 획득 후 기본 데미지(값 A), HUD 상태 확인 후 검증을 시작한다.
4.  **QA 검증 기준**
    - TC 1 : 유물 장착
    - TC 2 : 유물 해제
    - TC 3 : [장착 검증] HUD 아이콘 표시 확인
    - TC 4 : [조건부 검증] 스킬 사용 -> 기본 공격 3회
    - TC 5 : [조건부 검증] (TC 4) 이후 기본 공격 1회
    - TC 6 : [조건부 검증] (TC 4에서 2회 공격 후) 스킬 재사용 -> 기본 공격 3회
    - TC 7 : [해제 검증] 효과 즉시 제거, HUD 아이콘 복구 확인
5.  **예상 결과**
    - TC 1 : 유물 장착 됨
    - TC 2 : 유물이 정상적으로 해제됨
    - TC 3 : 아이콘 생성됨
    - TC 4 : 기본 공격 3회 데미지 (A * 1.5) 적용
    - TC 5 : 기본 공격 데미지 (A)로 복구됨
    - TC 6 : 스택 3회로 갱신, 데미지 (A * 1.5) 적용
    - TC 7 : 효과 제거, 아이콘 삭제됨

### 처형 프로토콜

    - 효과 : 체력이 15% 이하인 일반 몬스터를 즉시 처치합니다. (엘리트/보스 몬스터에게는 적용되지 않음)
3.  **시나리오**
    - 유물 획득 후 HUD 상태 확인 후 검증을 시작한다.
4.  **QA 검증 기준**
    - TC 1 : 유물 장착
    - TC 2 : 유물 해제
    - TC 3 : [장착 검증] HUD 아이콘 표시 확인
    - TC 4 : [조건부 검증] 일반 몬스터 체력을 16%로 만듦
    - TC 5 : [조건부 검증] 일반 몬스터 체력을 15% 또는 14%로 만듦
    - TC 6 : [제한 확인] 엘리트/보스 몬스터 체력을 15% 이하로 만듦
    - TC 7 : [해제 검증] 효과 즉시 제거, HUD 아이콘 복구 확인
5.  **예상 결과**
    - TC 1 : 유물 장착 됨
    - TC 2 : 유물이 정상적으로 해제됨

    - TC 4 : 몬스터 즉사 안 함
    - TC 5 : 몬스터 즉시 처치됨
    - TC 6 : 몬스터 즉사 안 함
    - TC 7 : 효과 제거, 아이콘 삭제됨

### 역장 재생성기

1.  **기획 의도**
    - 최상위 방어 유물 (비 피격 시 보호막 생성, 최대 3개)
2.  **핵심 수치 (기획값)**
    - 분류 : 근원 프로세스 (방어 계열)

    - 효과 : 30초 동안 피격당하지 않으면, 추가 하트의 보호막이 1개 추가됩니다. (최대 3개)
3.  **시나리오**
    - 유물 획득 후 HUD 상태 확인 후 검증을 시작한다.
4.  **QA 검증 기준**
    - TC 1 : 유물 장착
    - TC 2 : 유물 해제
    - TC 3 : [장착 검증] HUD 아이콘 표시 확인
    - TC 4 : [조건부 검증] 30초, 60초, 90초, 120초 대기
    - TC 5 : [조건부 검증] (TC 4) 이후 피격, 다시 30초 대기
    - TC 6 : [해제 검증] 효과 즉시 제거, HUD 아이콘 복구 확인
5.  **예상 결과**
    - TC 1 : 유물 장착 됨
    - TC 2 : 유물이 정상적으로 해제됨
    - TC 3 : 아이콘 생성됨
    - TC 4 : 30초마다 보호막 1칸(최대 3칸) 획득
    - TC 5 : 보호막 1칸 재획득 (최대 3칸)
    - TC 6 : 효과 제거, 아이콘 삭제됨

### 최후의 저항

1.  **기획 의도**

2.  **핵심 수치 (기획값)**

    - 오염도 수치 : 0
    - 효과 : 죽었을 경우 하트 1개를 생성되며, 3초간 무적 상태가 됩니다. (게임 진행 간 1회)
3.  **시나리오**
    - 유물 획득 후 HUD 상태 확인 후 검증을 시작한다.

    - TC 1 : 유물 장착
    - TC 2 : 유물 해제
    - TC 3 : [장착 검증] HUD 아이콘 표시 확인
    - TC 4 : [조건부 검증] 플레이어 사망
    - TC 5 : [횟수 제한] (TC 4) 이후 다시 사망
    - TC 6 : [횟수 제한] (TC 4) 이후 유물 해제 -> 재장착 -> 사망
    - TC 7 : [해제 검증] HUD 아이콘 복구 확인

    - TC 4 : 하트 1칸으로 부활, 3초 무적 적용됨
    - TC 5 : 부활 효과 발동 안 함
    - TC 6 : 부활 효과 발동 안 함

### 자원 순환 장치

1.  **기획 의도**
    - 최상위 파밍 유물 (경험치 및 아이템 획득 극대화)
2.  **핵심 수치 (기획값)**
    - 분류 : 근원 프로세스 (유틸리티 계열)
    - 오염도 수치 : 0
    - 효과 : 획득하는 경험치 50% 추가 획득, 오염된 프로세스 확률이 10% 증가합니다.
3.  **시나리오**
    - 유물 미장착 상태에서 획득 경험치(값 A), 오염된 프로세스 드랍률(값 B), HUD 상태 확인 후 검증을 시작한다. (예: 상자 10%)
4.  **QA 검증 기준**
    - TC 1 : 유물 장착
    - TC 2 : 유물 해제
    - TC 3 : [장착 검증] HUD 아이콘 표시 확인
    - TC 4 : [장착 검증] 몬스터 처치 (경험치 A * 1.5 확인)
    - TC 5 : [장착 검증] 상자 오픈 또는 몬스터 처치 (드랍률 B+10% 확인 - 합연산 추정)
    - TC 6 : [해제 검증] 획득 경험치(A), 드랍률(B), HUD 복구 확인
5.  **예상 결과**
    - TC 1 : 유물 장착 됨
    - TC 2 : 유물이 정상적으로 해제됨
    - TC 3 : 아이콘 생성됨
    - TC 4 : 경험치 1.5배 적용됨
    - TC 5 : 드랍률 +10%p 적용됨
    - TC 6 : 경험치, 드랍률 원복, 아이콘 삭제됨
