# 정화된 프로세스 (유물) QA 테스트 케이스 제공 문서
## 정화된 프로세스
**참고 : 정화된 유물은 오염도 수치가 없습니다.**

### 안정화된 에너지 코어

1.  **기획 의도**
    - '과부하 코어' 정화 보상 (공격력 증가 + 확률적 공속 버프)
2.  **핵심 수치 (기획값)**
    - 분류 : 정화된 프로세스 (공격 계열)
    - 오염도 수치 : 0
    - 효과 : 기본 공격력이 15% 증가하고, 공격 시 10% 확률로 3초간 공격 속도가 50% 증가 합니다. (누적X)
    - 정화 전 프로세스 : 과부하 코어
3.  **시나리오**
    - '과부하 코어' 정화 후 획득한 상태에서 기본 데미지(값 A), 공속(값 B), HUD 상태 확인 후 검증을 시작한다.
4.  **QA 검증 기준**
    - TC 1 : 유물 장착
    - TC 2 : 유물 해제
    - TC 3 : [장착 검증] 데미지 (A * 1.15), HUD 아이콘 표시 확인
    - TC 4 : [조건부 검증] '허수아비' 100회 타격
    - TC 5 : [해제 검증] 데미지(A), HUD 아이콘 복구 확인
5.  **예상 결과**
    - TC 1 : 유물 장착 됨
    - TC 2 : 유물이 정상적으로 해제됨
    - TC 3 : 데미지 15% 증가, 아이콘 생성됨
    - TC 4 : 약 10회 3초간 공속 50% 버프 발동, 중첩 불가(시간만 갱신)
    - TC 5 : 데미지 원복, 아이콘 삭제됨
