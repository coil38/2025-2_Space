# 오염된 프로세스 (유물, 이중 효과) QA 테스트 케이스 제공 문서
## 2. 오염된 프로세스: 이중 효과

### 분노 제어 해제 프로토콜

1.  **기획 의도**
    - 잃은 체력 비례 공격력 증가, 단 최대 체력 감소 (광전사 컨셉)
2.  **핵심 수치 (기획값)**
    - 분류 : 오염된 프로세스 - 이중 효과 (공격 계열)
    - 오염도 수치 : 35
    - 효과 : 잃은 하트 1칸 당 공격력이 15% 증가하지만, 최대 하트가 1칸 감소합니다.
    - 제한 : '최후의 보류', '과부하 역류 회로' 장착 시 장착 불가능. 효과 적용 중 해제 시 즉시 해제.
3.  **시나리오**
    - (최대 하트 5칸 기준) 유물 미장착 상태에서 기본 데미지(값 A), 총 오염도(값 B), HUD 상태 확인 후 검증을 시작한다.
4.  **QA 검증 기준**
    - TC 1 : [제한 확인] '최후의 보류' 장착 상태에서 본 유물 장착 시도
    - TC 2 : [제한 확인] '과부하 역류 회로' 장착 상태에서 본 유물 장착 시도
    - TC 3 : 유물 장착 (현재 4/4칸)
    - TC 4 : [장착 검증] 최대 하트 4칸, 데미지 A, 오염 (B+35), HUD 아이콘 표시 확인
    - TC 5 : [조건부 검증] 1칸 피격 (3/4칸). 데미지 (A * 1.15) 확인
    - TC 6 : [조건부 검증] 2칸 추가 피격 (1/4칸). 데미지 (A * 1.45) 확인
    - TC 7 : [조건부 검증] 1칸 회복 (2/4칸). 데미지 (A * 1.30) 확인 (효과 감소 확인)
    - TC 8 : 유물 해제
    - TC 9 : [해제 검증] 최대 하트(5칸), 데미지(A), 오염(B), HUD 복구 확인
5.  **예상 결과**
    - TC 1 : 유물 장착 실패
    - TC 2 : 유물 장착 실패
    - TC 3 : 유물 장착 됨
    - TC 4 : 최대 하트 1칸 감소, 오염도 35 증가, 아이콘 생성됨
    - TC 5 : 데미지 15% 증가 적용됨
    - TC 6 : 데미지 45% 증가 적용됨
    - TC 7 : 데미지 30% 증가 적용됨 (효과 감소 확인)
    - TC 8 : 유물 정상 해제됨
    - TC 9 : 최대 하트, 데미지, 오염도 원복, 아이콘 삭제됨

### 출력 증폭 회로

1.  **기획 의도**
    - 하이 리스크-하이 리턴의 '유리대포' 빌드
2.  **핵심 수치 (기획값)**
    - 분류 : 오염된 프로세스 - 이중 효과 (공격 계열)
    - 오염도 수치 : 50
    - 효과 : 모든 공격력이 2배가 되지만, 받는 모든 피해가 2배로 증가합니다.
    - 제한 : 효과 적용 중 해제 시 즉시 해제.
3.  **시나리오**
    - 유물 미장착 상태에서 기본 데미지(값 A), 받는 피해(값 B), 총 오염도(값 C), HUD 상태 확인 후 검증을 시작한다.
4.  **QA 검증 기준**
    - TC 1 : 유물 장착
    - TC 2 : 유물 해제
    - TC 3 : 장착 검증
        - 데미지 : (A * 2)
        - 받는 피해 : (B * 2)
        - 오염 : (C + 50)
        - HUD 아이콘 표시 확인
    - TC 4 : 해제 검증
        - 데미지 : (A)
        - 받는 피해 : (B)
        - 오염 : (C)
        - HUD 아이콘 제거 확인
5.  **예상 결과**
    - TC 1 : 유물 장착 됨
    - TC 2 : 유물이 정상적으로 해제됨
    - TC 3:
        - '데미지'가 2배로 증가
        - '받는 피해'가 2배로 증가
        - '오염도'가 50만큼 증가
        - 아이콘이 즉시 생성됨
    - TC 4:
        - '데미지'가 '값 A'로 복구
        - '받는 피해'가 '값 B'로 복구
        - '오염도'가 '값 C'로 복구
        - 아이콘이 즉시 삭제됨

2.  **핵심 수치 (기획값)**

3.  **시나리오**
    - 유물 미장착 상태에서 최대 하트(값 A), 이동 속도(값 B), 총 오염도(값 C), HUD 상태 확인 후 검증을 시작한다.
4.  **QA 검증 기준**

    - TC 2 : [제한 확인] '과부하 역류 회로' 장착 상태에서 본 유물 장착 시도

    - TC 1 : 유물 장착 실패
    - TC 2 : 유물 장착 실패
    - TC 3 : 유물 장착 됨
    - TC 4 : 최대 하트 +2칸, 이속 -15%, 오염 30 증가, HUD 표시됨
    - TC 5 : 장착 해제 실패
    - TC 6 : 유물 정상 해제되나, 현재 채워진 하트 2칸 감소

### 위기 대응 프로토콜

3.  **시나리오**

    - TC 3 : [조건부 검증] 현재 하트 1칸(이하)으로 만듦. 1분간 공속/이속 +30% 버프 발동 확인

    - TC 8 : 유물 해제 (버프 없는 상태)
    - TC 9 : [해제 검증] 오염(B), HUD 복구 확인
