# 오염된 프로세스 (유물, 단일효과) QA 테스트 케이스 제공 문서
## 1. 오염된 프로세스: 단일 효과

### 소형 공격 연산기

1.  **기획 의도**
    - 기본적인 공격력 증가 유물
2.  **핵심 수치 (기획값)**
    - 분류 : 오염된 프로세스 - 단일 효과 (공격 계열)
    - 오염도 수치 : 10
    - 효과 : 공격력이 8% 증가합니다.
3.  **시나리오**
    - 유물 미장착 상태에서 기본 데미지(값 A), 총 오염도(값 B), HUD 상태 확인 후 검증을 시작한다.
4.  **QA 검증 기준**
    - TC 1 : 유물 장착
    - TC 2 : 유물 해제
    - TC 3 : 장착 검증
        - 데미지 : (A * 1.08)
        - 오염 : (B + 10)
        - HUD 아이콘 표시 확인
    - TC 4 : 해제 검증
        - 데미지 : (A)
        - 오염 : (B)
        - HUD 아이콘 제거 확인
5.  **예상 결과**
    - TC 1 : 유물 장착 됨
    - TC 2 : 유물이 정상적으로 해제됨
    - TC 3:
        - '데미지'가 1.08배로 증가
        - '오염도'가 10만큼 증가
        - 아이콘이 즉시 생성됨
    - TC 4:
        - '데미지'가 '값 A'로 복구
        - '오염도'가 '값 B'로 복구
        - 아이콘이 즉시 삭제됨
