# 일반 스테이지 설계
- 문서 버전 : 0.0.2
- 문서 업데이트 : 2025.11.06


## 개요
본 문서는 스테이지의 절차적 생성 규칙과 각 룸의 상세 파라미터를 정의합니다.\
일반 스테이지는 전투, 이벤트, 보상 등 다양한 룸이 절차적으로 생성되는 게임의 기본 스테이지입니다. 플레이어는 이 스테이지를 탐험하며 성장에 필요한 대부분의 재화와 유물을 획득하게 됩니다.


## 스테이지 절차적 생성 로직
일반 스테이지는 아래 정의된 규칙에 따라 플레이어가 진입할 때마다 새로운 구조로 생성됩니다.
1. 총 룸 개수 결정 : 스테이지 생성 시, 4~5개 사이의 정수가 무작위로 결정됩니다.
2. 룸 순차 배치 : 결정된 총 룸 개수만큼 아래 규칙에 따라 룸을 순서대로 배치합니다.
   - 첫 번째 룸 : 상위 룸 등장 확률 표에 따라 무작위로 선택됩니다.
   - 두 번째 룸 이후 : 이전 룸의 종류와 남은 최대 등장 횟수를 고려하여 다음 룸을 무작위로 선택합니다.
3. 배치 제약 조건:
   - 최대 등장 횟수 : 각 룸 타입은 한 스테이지 내에서 정해진 최대 횟수를 초과하여 등장할 수 없습니다.
   - 연속 배치 불가 : 전투가 없는 룸(정화기 룸, 교환기 룸, 보급 상자 룸)은 연속으로 배치될 수 없습니다. (예 : [정화기 룸 -> 보급 상자 룸] 불가)
4. 등장 횟수 초기화:
   - 각 룸의 등장 횟수는 한 스테이지 내에서 누적 계산 되며, 해당 스테이지를 클리어하면 모든 카운트가 초기화됩니다.


## 룸 상세 설계 및 파라미터

### 상위 룸 등장 확률 및 최대 횟수
| 룸 종류 | 등장 확률 | 최대 등장 횟수 |
| :--- | :--- | :--- |
| 전투 룸 | 60% | 8 |
| 정화기 룸 | 10% | 1 |
| 교환기 룸 | 10% | 1 |
| 보급 상자 룸 | 20% | 3 |

### 룸 상세 파라미터

#### 전투 룸
 - 공통 사항 : 룸의 모든 몬스터를 처치해야 다음 룸으로 가는 문이 열립니다.
 - 상세 분류 및 확률 및 규칙 : 전투 룸으로 결정되었을 때, 아래 확률과 최대 등장 횟수 내에서 세부 타입이 결정됩니다.

| 상세 종류 | 등장 확률 | 최대 등장 횟수 | 몬스터 웨이브 | 특수 보상
| :--- | :--- | :--- | :--- | :--- |
| 일반 전투 룸 | 50% | 8 | 1 ~ 2회 | - |
| 필드 공격 룸 | 20% | 2 | 1 ~ 2회 | - |
| 지정 몬스터 룸 | 20% | 2 | 1 ~ 2회 | - |
| 엘리트 몬스터 룸 | 10% | 1 | 1 ~ 2회 | 클리어 시 20# 확률로 **히든 상자** 지급 |
- 개발 파라미터:

| 파라미터 | 설명 | 예시 값 |
| :--- | :--- | :--- |
| 몬스터 ID | 이 룸에서 등장할 수 있는 몬스터 목록 데이터 ID (Reward.json 참조) | MOB_Can, MOB_STUMP |
| 보상 테이블 ID | 룸 클리어 시 드랍될 보상 목록 데이터 ID (reward.json 참조) |  1001, 1002 |
| 필드 기믹 | (필드 공격 룸 전용) 필드에 적용될 위협 요소 | |

#### 정화기 룸
- 설명 : 플레이어가 보유한 [리스크 효과] 오염된 프로세스를 '정화된 프로세스'로 변환할 수 있는 이벤트 룸입니다. 몬스터가 등장하지 않습니다.
- 개발 파라미터:

| 파라미터 | 설명 | 값 |
| :--- | :--- | :--- |
| 오브젝트 프리펩 | 룸 구석에 배치될 정화기, 파괴된 우주선 잔해 오브젝트의 프리팹 이름 | |
| 상호작용 모델 | 정화기, 파괴된 우주선 잔해 주변에 배치되는 모델 | |
| 사용 제한 | 한 정화기 당 최대 사용 가능 횟수 | 3 |
| UI 플로우 | 상호작용 시, 정화할 '리스크 유물'을 선택하는 UI를 호출 | |

#### 교환기 룸
- 설명 : 플레이어가 보유한 '오염된 프로세스'를 다른 종류의 '오염된 프로세스'로 무작위 교환할 수 있는 이벤트 룸입니다. 몬스터는 등장하지 않습니다.
- 개발 파라미터:

| 파라미터 | 설명 | 값 |
| :--- | :--- | :--- |
| 오브젝트 프리팹 | 룸 구석에 배치될 정화기, 파괴된 우주선 잔해 오브젝트의 프리팹 이름 | |
| 상호작용 모델 | 교환기, 파괴된 우주선 잔해 주변에 배치되는 모델 | |
| 사용 제한 | 한 교환기 당 최대 사용 가능 횟수 | 5 |
| 교환 로직 | 교환 시, 현재 보유한 '오염된 프로세스'중 하나를 소모하고, 동일 등급의 다른'오염된 프로세스'1개를 무작위 획득 | - |

#### 보급 상자 룸
- 설명 : 룸 내부의 랜덤한 위치에 스폰되는 보급 상자를 영어 보상을 획득하는 보상 룸입니다. 몬스터는 등장하지 않습니다.
- 개발 파라미터:

| 파라미터 | 설명 | 값 |
| :--- | :--- | :--- |
| 오브젝트 프리팹 | 룸의 랜덤 위치에 배치될 보급 상자 프리팹 이름 | |
| 상호작용 | 상호작용(F) 키를 누르면 열리며 내용물이 드랍 | - |
| 보상 테이블 ID | 상자에서 드랍될 아이템 목록 데이터 ID (reward.json 참조) | 1001, 1002 |


## 데이터 연동
- 몬스터 : 모든 몬스터의 스탯과 정보는 enemy_balance.json 파일을 참조합니다.
- 보상 : 모든 보상 아이템 (유물)의 상세 정보와 드랍률은 reward.json 파일을 참조합니다.
- 오브젝트 : 룸에 배치되는 모든 상호작용 오브젝트(정화기, 상자 등)는 지정된 프리팹 이름을 사용하여 인스턴트화합니다.
