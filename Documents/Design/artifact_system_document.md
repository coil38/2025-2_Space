# 프로세스(유물) 시스템 설계
게임 내 핵심 재화의 종류, 획득처, 드랍률 정의
- 문서 버전 : 0.0.1
## 개요
본 문서는 게임의 핵심 성장 동력이 되는 '프로세스(유물)'의 상세 시스템을 정의하는 것을 목적으로 한다. 각 유물의 종류, 특성. 획득 방법 및 확률을 명확히 규정하여 게임 밸런스와 콘텐츠 설계의 기반을 마련한다.
## 핵심 재화 정의 : 프로세스(유물)
게임의 핵심 재화는 '프로세스'로 칭하며, 총 3가지의 상위 분류로 나뉜다.
### 오염된 프로세스
- 설명
  - 핵심 성장 유물이며, 장착 중량이 걸려 있는 유물이다. 일반 몬스터 및 보상 상자 등 여러 곳에서 획득이 가능하다. 장착 중량이 걸려 있는 만큼 원하는 만큼 장착하기에는 제한이 걸린다.
- 획득 방법
  - 몬스터 드랍 : 10%
  - 상자 드랍 : 50%
  - 히든 상자 : 100%
  - 보급 상자 : 70%
- 오염도 수치 (장착 중량)
  - 모든 '오염된 프로세스'는 고유의 '오염도 수치'를 가진다.
  - 플레이어는 '오염도 게이지'(최대 장착 가능 중량) 한도 내에섬나 유물을 장착할 수 있다.
- 분류 : 단일 효과를 제외한 모든 분류에는 공격, 방어, 유틸리티 효과로 나뉜다.
  - 단일 효과: 플레이어에게 이익이 되는 단일 효과(공격력, 하트 증가 등)를 부여한다.
  - 리스크 효과: 플레이어에게 해가 되는 부정적 효과만 부여한다. 이 유물은 '프로세스 정화기'를 통해 정화할 수 있다.
  - 이중 효과: 하이 리스크, 하이 리턴. 이익이 되는 효과와 해가 되는 효과를 동시에 부여한다.
### 정화된 프로세스
- 설명
  - 업그레이드된 유물. '리스크 효과'만 있던 오염된 프로세스를 정화함으로써 부정적 효과를 제거하고 긍정적 효과만 남긴 유물이다. 부여되어 있던 '오염도 수치'가 사라져 장착 중량을 요구하지 않는 것이 가장 큰 특징이다.
- 획득 방법
  - 프로세스 정화기 : '리스크 효과'오염된 프로세스를 정화할 경우 100% 확률로 획득.
  - 참고 : 리스크 유물의 종류마다 정해진 '정화된 프로세스'로 변환된다.
- 오염도 수치 (장착 중략)
  - 없음 (0)
- 분류
  - 공격
  - 방어
  - 유틸리티
### 근원 드로세스 
- 설명
  - 상위 유물. 일반/엘리트 몬스터에게서는 획득이 불가능하며 특수한 루트로만 획득 가능하다.
  - 오염도 수치를 요구하지 않지만, 플레이어는 최대 3개까지만 장착할 수 있다.
- 획득 방법
  - 히든 상자 : 100%
  - 중간 보스 처치 보상 : 100%
  - 보급 상자 : 20%
- 오염도 수치 (장착 중량)
  - 없음 (0)
- 장첵 제한
  - 플레이어 당 최대 3개까지 장착 가능
## 주요 획득처별 드랍률 요약
| 획득처 | 오염된 프로세스 | 정화된 프로세스 | 근원 프로세스 |
| :--- | :---: | :---: | :---: |
| 일반 몬스터 드랍 | 10% | - | - |
| 상자 드랍 | 50% | - | - |
| 보급 상자 | 70% | - | 20% |
| 히든 상자 | 100% | - | 100% |
| 중간 보스 처치 | - | - | 100% |
| 프로세스 정화기 | - | 100% (변환) | - |
