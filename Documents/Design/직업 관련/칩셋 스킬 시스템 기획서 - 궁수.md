# 칩셋 스킬 시스템 기획서 \- 궁수

---

최신 업데이트 : 2025.11.05  
---

## 몬스터 개요

* 직업 이름 : 궁수  
* 분류 : 플레이어 핵심 전투 시스템  
* 역할 : 플레이어가 활을 사용하여 몬스터와 교전하는 모든 방식을 정의합니다.  
* 핵심 로직:  
  * 플레이어는 평타와 고유 스킬을 사용합니다.  
  * 모든 공격(평타, 스킬1, 2, 3)은 동일한 애니메이션을 재생합니다.  
  * 시스템은 어떤 공격이 시작되었는지 판별한 후, 애니메이션의 특정 프레임(F.11(약 0.18초))에 투사체를 생성하여 발사합니다.  
  * 모든 공격은 마우스 커서의 위치를 조준하여 발사됩니다.

## 스킬 목록 및 상세

| 스킬 종류 | 입력 키 | 사용 애니메이션 | 사용할 투사체 | 핵심 로직 |
| :---- | :---- | :---- | :---- | :---- |
| 평타 | 마우스 좌클릭 | PLAYER\_Bow\_Attack | Arrow\_Normal | 단일 대상에게 날아가는 기본 화살 |
| 스킬 1 | Q |  | Arrow\_Normal | 적에게 적중 시, 주변의 다른 적을 찾아 최대 5회 튕깁니다. |
| 스킬 2 | E |  | Arrow\_Normal | 마우스 방향으로 1개, 좌우 대각선으로 4개의 추가 발사체를 동시에 발사합니다. |
| 스킬 3 | R |  | Arrow\_Giant | 크고 강력한 투사체를 1개 발사합니다. 이 화살은 넓은 공격 범위를 가지며 모든 적을 관통합니다. |

## 시스템 작동 로직

| 입력 감지 | 플레이어가 평타 또는 스킬 1,2,3의 입력키를 누릅니다. |  |
| :---- | :---- | :---- |
|  | 시스템은 해당 스킬의 쿨다운이 완료되었는지 확인합니다. |  |
| 애니메이션 재생 | 플레이어 캐릭터는 현재 마우스 커서 바라보며 애니메이션을 1회 재생합니다. |  |
|  | 동시에 해당 스킬의 쿨다운 타이머가 시작됩니다. |  |
|  | 애니메이션 재생 중에는 평타 및 스킬을 사용 할 수 없습니다. |  |
| 투사체 생성 | 애니메이션이 발사 타이밍은 F.11(약 0.18초)에 투사체를 발사합니다. |  |
|  | 평타의 경우 | Arrow\_Normal 1개를 마우스 방향으로 발사합니다. |
|  | 스킬 1의 경우 | Arrow\_Normal 1개를 마우스 방향으로 발사합니다. (이 투사체는 자체적으로 튕기는 로직을 가짐) |
|  | 스킬 2의 경우 | Arrow\_Normal 5개를 각각 정면 1개, 좌대각 2개, 우대각 2개를 동시에 발사합니다. |
|  | 스킬 3의 경우 | 1개를 마우스 방향으로 발사합니다. (이 투사체는 큰 충돌 박스와 관통 속성을 가짐) |
| 로직 종료 | 애니메이션이 종료되면 플레이어는 기본 자세로 돌아갑니다. |  |

## 시스템 구현

| 구분 | 항목 | 내용 |
| ----- | :---- | :---- |
| 입력 | 플레이어 입력 | 마우스 좌클릭, Q, E, R 입력 감지 |
|  | 마우스 위치 | 매 프레임 마우스 커서의 좌표(조준점)를 갱신 |
|  | 쿨다운 확인 | 각 스킬의 쿨다운 타이머가 0인지 확인 |
| 출력 | 상태 전환 | 플레이어 상태를 공격 중으로 변경 |
|  | 애니메이션 재생 | PLAYER\_Bow\_Attack 애니메이션 1회 재생 및 플레이어 상체 회전 |
|  | 투사체 생성 | 입력된 스킬 종류에 맞는 투사체를 조준점에 맞춰 생성 |
|  | 쿨다운 처리 | 스킬 사용 시, 해당 스킬의 쿨다운 타이머를 즉시 시작  |
