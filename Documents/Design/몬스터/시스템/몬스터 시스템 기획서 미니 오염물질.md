# 몬스터 시스템 기획서 \- 미니 오염물질

최신 업데이트 : 2025.10.10  
---

## 몬스터 개요

* 몬스터 이름 : 미니 오염물질 (MOB\_MiniP)  
* 분류 : 엘리트 몬스터 (기회주의적 암살자형)  
* 역할 : 플레이어의 방심을 유도한 후, 피하기 어려운 정밀 타격과 함께 성장을 방해하는 치명적인 디버프를 거는 교란자 역할을 한다.  
* 핵심 로직 : 천천히 접근하여 3초간의 긴 조준 시간을 가진 후, 매우 빠른 돌진으로 공격한다. 공격 성공 시 20% 확률로 플레이어의 유물(프로세스) 중 하나를 무력화시킨다. 공격 후에는 즉시 빠른 속도로 도망쳐 거리를 벌린다.

## 행동 패턴

| 대기 (Idle) |  |
| :---- | :---- |
| 플레이어가 **인식 범위 밖**에 있거나, **공격 쿨다운 상태**일 때의 기본 상태입니다. MOB\_MiniP\_Idle 애니메이션을 반복 재생합니다. |  |
| 재생 시간 | 1.5초, 반복 |
| 전환 조건 | 플레이어가 인식 범위 안으로 들어오고, 공격 쿨다운이 아닐 경우 **추격(Move)상태로 전환**됩니다. |

| 추격 (Move) |  |
| :---- | :---- |
| 플레이어가 '인식 범위' 안에 있지만 '돌진 준비 범위' 밖에 있을 때의 상태 MOB\_MiniP\_Idle 애니메이션을 반복 재생합니다. |  |
| 재생 시간 | 0.67초, 반복 |
| 전환 조건 1 | 플레이어가 **근접 공격 범위** 안으로 들어오면 **공격 준비(Atk\_Ready) 상태로 전환**됩니다. |
| 전환 조건 2 | 플레이어가 **인식 범위** 밖으로 벗어나면 **대기(Idle) 상태로 전환**됩니다. |

| 공격 준비 (Atk\_Ready) |  |
| :---- | :---- |
| 3초 동안 그 자리에서 돌진을 준비합니다. MOB\_MiniP\_Atk\_Ready 애니메이션을 1회 재생합니다. 처음 2.5초 동안은 계속해서 플레이어 방향으로 몸을 돌리며 조준을 갱신한다. 마지막 0.5초 동안은 조준을 고정한다. |  |
| 재생 시간 | 3초, 1회 |
| 슈퍼 아머 상태 | 이 상태에서는 플레이어에게 피격당해도 경직 되지 않고 공격을 계속 준비합니다. |
| 전환 조건 | 애니메이션 재생이 끝나면 **공격(Attack) 상태로 전환**됩니다. |

| 공격 (Attack) |  |
| :---- | :---- |
| MOB\_MiniP\_Atk\_Start 애니메이션을 재생하며 돌진 거리만큼 빠르게 전진합니다. |  |
| 재생 시간 | 0.33초, 1회 |
| 슈퍼 아머 상태 | 이 상태에서는 플레이어에게 피격당해도 경직 되지 않습니다. |
| 전환 조건 | 돌진 거리에 도달하거나 벽에 부딪히면 즉시 **도망(Run) 상태로 전환**됩니다.. |

| 도망 (Run) |  |
| :---- | :---- |
| 3초 동안 플레이어 반대 방향으로 빠르게 이동합니다. MOB\_MiniP\_Move\_Run 애니메이션을 반복 재생합니다. |  |
| 재생 시간 | 0.33초, 1회 |
| 전환 조건 | 3초의 도망 시간이 지나면 공격 쿨다운 타이머를 작동 시키고 **대기(Idle) 상태로 전환**됩니다. |

| 피격 (Hit) |  |
| :---- | :---- |
| **대기상태**에서 플레이어에게 공격받았을 때의 상태입니다. MOB\_MiniP\_Hit 애니메이션을 재생하며 짧은 시간 동안 행동 불능이 됩니다. |  |
| 재생 시간 | 0.25초, 1회 |
| 시각 효과 | 피격 순간 몬스터의 2D 스프라이트가 **0.25초 동안 붉은색으로 점멸**하여 피격 사실을 명확하게 보여줍니다. |
| 전환 조건 | 애니메이션 재생이 끝나면 이전 상태로 돌아갑니다. |

| 사망 (Death) |  |
| :---- | :---- |
| 해당 몬스터의 체력이 HP \= 0일 때 상태입니다. MOB\_MiniP\_Death 애니메이션을 재생하며 종료 될 때 해당 몬스터를 제거합니다. |  |
| 재생 시간 | 1초, 1회 |
| 사망 조건 | 몬스터의 HP \= 0 |

## 특수 능력 : 프로세스 오염

| 트리거 | 공격(돌진)이 플레이어에게 적중했을 때, 20% 확률로 발동합니다. |  |
| :---- | :---- | ----- |
| 효과 | 플레이어가 현재 장착 중인 모든 프로세스(오염된, 정화된, 근원) 중 **무작위로 1개를 선택**합니다. |  |
|  | 선택된 프로세스는 **해당 스테이지가 끝날 때까지 모든 효과가 비활성화**됩니다. (장착 해제와 유사) |  |
|  | 플레이어에게 어떤 프로세스가 비활성화되었는지 시각적인 UI 알림을 표시합니다. |  |
|  | 비활성화 된 프로세스는 해제가 불가능합니다. |  |

## 기능 요약

| 정의 | 긴 조준 후 빠른 돌진으로 공격하고 즉시 도망가는 치고 빠지기형 엘리트 몬스터 |
| :---- | :---- |
| 핵심 특징 | 공격 성공 시 20% 확률로 플레이어의 유물(프로세스) 1개를 무력화시키는 특수 능력을 보유  |
| 역할 | 플레이어의 성장을 직접적으로 방해하고, 긴 선딜레이를 공략해야 하는 과제를 제시하는 교란자 |
| 목표 | 플레이어가 몬스터의 긴 준비 시간을 역으로 이용하여 공격하는 패턴을 학습하도록 유도하고, 엘리트 몬스터의 위협도를 체감시킴 |

## 시스템 구현

| 구분 | 항목 | 내용 |
| ----- | :---- | :---- |
| 입력 | 플레이어 감지 | 플레이어의 위치를 주기적으로 확인하여 **인식 범위** 및 **돌진 준비 범위** 내에 있는지 판단 |
|  | 플레이어 피격 감지 | 공격 상태일 때 **몬스터의 공격 판정**과 **플레이어의 충돌을 감지** |
|  | 몬스터 피격 감지 | **플레이어의 공격 판정**과 **몬스터의 피격 판정**의 충돌을 감지 |
|  | 타이머 | 도망 시간, 공격 쿨다운 등 계산 |
| 출력 | 상태 전환 | 입력 조건에 따라 몬스터의 AI 상태를 변경하고, 그에 맞는 애니메이션 ID를 재생 |
|  | 이동/돌진/도망 처리 | 각 상태에 맞는 속도와 방향으로 몬스터를 이동시킴 |
|  | 사망 처리(분열) | HP가 0이 되었을 때, 분열 횟수를 확인하여 **분열 로직** 또는 **완전 소멸 로직**을 실행 |
|  | 조준 처리 | 공격 준비 상태일 때 플레이어 방향으로 몬스터를 회전시키다가 마지막 0.5초 동안 회전을 멈춤 |
|  | 피해 및 특수 능력 처리 | 플레이어 감지 성공 시, 플레이어의 체력을 감소시키고 20% 확률로 ‘프로세스 오염’효과를 발동 시켜 무작위 유물 1개를 비활성화시킴 |
|  | 데이터 저장 | 몬스터의 현재 HP 데이터를 관리하며, 0이 되면 사망 처리 |
