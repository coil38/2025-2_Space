# 몬스터 시스템 기획서 \- 돌 전사

---

최신 업데이트 : 2025.10.08  
---

## 몬스터 개요

* 몬스터 이름 : 돌 전사 (MOB\_Stone)  
* 분류 : 일반 몬스터 (근접, 탱커형)  
* 역할 : 높은 체력을 바탕으로 플레이어의 앞을 가로막고 꾸준히 피해를 누적시키는 '움직이는 장애물' 역할을 합니다.  
* 핵심 로직 : 특별한 능력 없이 플레이어를 인식하면 끈질기게 추격하여 단순한 근접 공격을 반복합니다. 높은 체력이 가장 큰 특징입니다.

## 행동 패턴

| 대기 (Idle) |  |
| :---- | :---- |
| 플레이어가 **인식 범위 밖**에 있거나, **공격 쿨다운 상태**일 때의 기본 상태입니다. MOB\_Stone\_Idle 애니메이션을 반복 재생합니다. |  |
| 재생 시간 | 2초, 반복 |
| 전환 조건 | 플레이어가 인식 범위 안으로 들어오고, 공격 쿨다운이 아닐 경우 **추격(Move)상태로 전환**됩니다 |

| 추격 (Move) |  |
| :---- | :---- |
| 플레이어가 인식 범위 안에 있지만 근접 공격 범위 밖에 있을 때의 상태 MOB\_Stone\_Move 애니메이션을 반복 재생합니다. |  |
| 재생 시간 | 1초, 반복 |
| 전환 조건 1 | 플레이어가 **돌진 준비 범위** 안으로 들어오면 **공격 준비 상태로 전환**됩니다. |
| 전환 조건 2 | 플레이어가 **인식 범위** 밖으로 벗어나면 **대기 상태로 전환**됩니다. |

| 공격 준비 (Atk\_Ready) |  |
| :---- | :---- |
| 0.67초 동안 공격을 준비합니다. MOB\_Stone\_Atk\_Ready 애니메이션을 1회 재생합니다. |  |
| 재생 시간 | 0.67초, 1회 |
| 슈퍼 아머 상태 | 이 상태에서는 플레이어에게 피격당해도 경직 되지 않고 공격을 계속 준비합니다. |
| 전환 조건 | 애니메이션 재생이 끝나면 **공격 상태로 전환**됩니다. |

| 공격 (Attack) |  |  |
| :---- | :---- | :---- |
| MOB\_Stone\_Atk\_Start \-\> MOB\_Stone\_Atk\_End 애니메이션을 순차적으로 재생하며 플레이어를 공격합니다. |  |  |
| 재생 시간 | MOB\_Stone\_Start | 0.2초, 1회 |
|  | MOB\_Stone\_End | 0.5초, 1회 |
| 슈퍼 아머 상태 | 이 상태에서는 플레이어에게 피격당해도 경직 되지 않습니다. |  |
| 전환 조건 1 | 애니메이션 재생이 끝나면, 공격 쿨다운 동안 잠시 멈췄다가 플레이어의 위치를 확인 하여 **추격** 또는 **공격 준비 상태로 전환**됩니다. |  |
| 전환 조건 2 | 플레이어가 인식 범위 밖이라면 **대기 상태로 전환됩니다.** |  |

| 피격 (Hit) |  |
| :---- | :---- |
| **대기상태**에서 플레이어에게 공격받았을 때의 상태입니다. MOB\_Stone\_Hit 애니메이션을 재생하며 짧은 시간 동안 행동 불능이 됩니다. |  |
| 재생 시간 | 0.25초, 1회 |
| 시각 효과 | 피격 순간 몬스터의 2D 스프라이트가 **0.25초 동안 붉은색으로 점멸**하여 피격 사실을 명확하게 보여줍니다. |
| 전환 조건 | 애니메이션 재생이 끝나면 이전 상태로 돌아갑니다. |

| 사망 (Death) |  |
| :---- | :---- |
| 해당 몬스터의 체력이 HP \= 0일 때 상태입니다. MOB\_Stone\_Death 애니메이션을 재생하며 종료 될 때 해당 몬스터를 제거합니다다. |  |
| 재생 시간 | 1초, 1회 |
| 사망 조건 | 몬스터의 HP \= 0 |

## 기능 요약

| 정의 | 단순한 패턴을 가졌지만 체력이 매우 높은 근접 몬스터 |
| :---- | :---- |
| 핵심 특징 | 뛰어난 내구도. 플레이어의 공격을 버텨내며 전선을 유지 |
| 역할 | 플레이어의 화력을 시험하는 '딜링 체크' 몬스터이자, 다른 위험한 원거리 몬스터를 보호하는 방패 역할 |
| 목표 | 플레이어가 몬스터의 우선순위를 판단하고, 지속적인 피해를 주는 능력을 시험하게 함 |

## 시스템 구현

| 구분 | 항목 | 내용 |
| ----- | :---- | :---- |
| 입력 | 플레이어 감지 | 플레이어의 위치를 주기적으로 확인하여 **인식 범위** 및 **근접 공격 범위** 내에 있는지 판단 |
|  | 플레이어 피격 감지 | 공격 상태일 때 **몬스터의 공격 판정**과 **플레이어의 충돌을 감지** |
|  | 몬스터 피격 감지 | **플레이어의 공격 판정**과 **몬스터의 피격 판정**의 충돌을 감지 |
| 출력 | 상태 전환 | 입력 조건에 따라 몬스터의 AI 상태를 변경하고, 그에 맞는 애니메이션 ID를 재생 |
|  | 이동 처리 | 추격 상태일 때 플레이어 방향으로 몬스터를 회전 및 이동시킴 |
|  | 피해 처리 | 플레이어 피격 감지 성공 시, 플레이어의 HP 감소 처리 |
|  | 데이터 저장 | 몬스터의 현재 HP 데이터를 관리하며, 0이 되면 사망 처리 |
