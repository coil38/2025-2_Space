# 몬스터 시스템 기획서 \- 쓰레기 봉지

---

최신 업데이트 : 2025.10.09  
---

## 몬스터 개요

* 몬스터 이름 : 쓰레기 봉지 (MOB\_TBag)  
* 분류 : 일반 몬스터 (근접, 분열형)  
* 역할 : 단순한 근접 공격 패턴을 가졌지만, 사망 시 여러 마리로 분열하는 능력으로 플레이어에게 지속적인 압박과 다수 전투 상황을 유발합니다.  
* 핵심 로직 : 플레이어를 추격하여 근접 시 박치기 공격을 합니다. HP가 0이 되면, 분열 횟수를 체크하여 분열하거나 완전히 사망합니다.

## 행동 패턴

| 대기 (Idle) |  |
| :---- | :---- |
| 플레이어가 **인식 범위 밖**에 있거나, **공격 쿨다운 상태**일 때의 기본 상태입니다. MOB\_TBag\_Idle 애니메이션을 반복 재생합니다. |  |
| 재생 시간 | 1.5초, 반복 |
| 전환 조건 | 플레이어가 인식 범위 안으로 들어오고, 공격 쿨다운이 아닐 경우 **추격(Move)상태로 전환**됩니다 |

| 추격 (Move) |  |
| :---- | :---- |
| 플레이어가 인식 범위 안에 있지만 근접 공격 범위 밖에 있을 때의 상태입니다. MOB\_TBag\_Idle 애니메이션을 반복 재생합니다. |  |
| 재생 시간 | 0.75초, 반복 |
| 전환 조건 1 | 플레이어가 **근접 공격 범위** 안으로 들어오면 **공격 준비 상태로 전환**됩니다. |
| 전환 조건 2 | 플레이어가 **인식 범위** 밖으로 벗어나면 **대기 상태로 전환**됩니다. |

| 공격 준비 (Atk\_Ready) |  |
| :---- | :---- |
| 0.83초 동안 공격을 준비합니다. MOB\_TBag\_Atk\_Ready 애니메이션을 1회 재생합니다. |  |
| 재생 시간 | 0.5초, 1회 |
| 슈퍼 아머 상태 | 이 상태에서는 플레이어에게 피격당해도 경직 되지 않고 공격을 계속 준비합니다. |
| 전환 조건 | 애니메이션 재생이 끝나면 **공격 상태로 전환**됩니다. |

| 공격 (Attack) |  |  |
| :---- | :---- | :---- |
| MOB\_TBag\_Atk\_Start \-\> MOB\_TBag\_Atk\_End 애니메이션을 순차적으로 재생하며 플레이어를 공격합니다. |  |  |
| 재생 시간 | MOB\_TBag\_Atk\_Start | 0.25초, 1회 |
|  | MOB\_TBag\_Atk\_End | 0.42초, 1회 |
| 슈퍼 아머 상태 | 이 상태에서는 플레이어에게 피격당해도 경직 되지 않습니다. |  |
| 전환 조건 1 | 애니메이션 재생이 끝나면, 공격 쿨다운 동안 잠시 멈췄다가 플레이어의 위치를 확인 하여 **추격** 또는 **공격 준비 상태로 전환**됩니다. |  |
| 전환 조건 2 | 플레이어가 인식 범위 밖이라면 **대기 상태로 전환됩니다.** |  |

| 피격 (Hit) |  |
| :---- | :---- |
| **대기상태** 및 **추격상태**에서 플레이어에게 공격받았을 때의 상태입니다. 피격 시 몬스터 몸 주변으로 작은 쓰레기가 떨어져 나옵니다. 오직 시각 효과입니다. MOB\_TBag\_Hit 애니메이션을 재생하며 짧은 시간 동안 행동 불능이 됩니다. |  |
| 재생 시간 | 0.33초, 1회 |
| 시각 효과 | 피격 순간 몬스터의 2D 스프라이트가 **0.25초 동안 붉은색으로 점멸**하여 피격 사실을 명확하게 보여줍니다. |
| 전환 조건 | 애니메이션 재생이 끝나면 이전 상태로 돌아갑니다. |

| 사망(분열) (Death) |  |
| :---- | :---- |
| 해당 몬스터의 체력이 HP \= 0일 때 상태입니다. 분열 횟수가 0보다 클 경우 작동합니다. MOB\_TBag\_Death\_Split 애니메이션을 재생하며 종료 될 때 해당 몬스터를 제거합니다다. |  |
| 재생 시간 | 1.25초, 1회 |
| 사망 조건 | 몬스터의 HP \= 0 분열 횟수 \> 0 |

| 최종 사망 (Death) |  |
| :---- | :---- |
| 해당 몬스터의 체력이 HP \= 0일 때 상태입니다. 분열 횟수가 0 일 경우 작동합니다. MOB\_TBag\_Death\_Final 애니메이션을 재생하며 종료 될 때 해당 몬스터를 제거합니다다. |  |
| 재생 시간 | 0.75초, 1회 |
| 사망 조건 | 몬스터의 HP \= 0 분열 횟수 \= 0 |

## 분열 로직

| 트리거 | 쓰레기 봉지 몬스터의 HP가 0이 되는 순간 발동합니다. |  |
| :---- | :---- | :---- |
| 조건 확인 | 시스템은 해당 몬스터의 분열 횟수를 확인합니다. |  |
|  | 분열 횟수 \> 0일 경우 (큰 쓰레기 봉지) | MOB\_TBag\_Death\_Split 애니메이션을 재생합니다. |
|  |  | 애니메이션이 끝나는 시점에 현재 몬스터의 위치에 2\~4마리의 작은 쓰레기 봉지 몬스터를 생성합니다. |
|  |  | 기존의 큰 쓰레기 봉지 몬스터 오브젝트는 소멸합니다. |
|  |  | 해당 몬스터에서는 ‘오염된 프로세스’가 드랍하지 않습니다. |
|  | 분열 횟수 \= 0일 경우 (작은 쓰레기 봉지) | MOB\_TBag\_Death\_Final 애니메이션을 재생합니다. |
|  |  | 애니메이션이 끝나면 몬스터 오브젝트는 소멸합니다. |

## 기능 요약

| 정의 | 사망 시 여러 개의 작은 개체로 나뉘는 근접 몬스터 |
| :---- | :---- |
| 핵심 특징 | 1차 사망 시 분열, 2차 사망 시 완전 소멸하는 2개의 생명력 |
| 역할 | 플레이어에게 광역 처리 능력의 중요성을 인지시키고, 다수의 적을 상대하는 난전 상황을 연출 |
| 목표 | 단순 일점사 방식의 전투에서 벗어나, 전투의 흐름과 적의 증원을 관리하는 전략적 플레이 유도 |

## 시스템 구현

| 구분 | 항목 | 내용 |
| ----- | :---- | :---- |
| 입력 | 플레이어 감지 | 플레이어의 위치를 주기적으로 확인하여 **인식 범위** 및 **돌진 준비 범위** 내에 있는지 판단 |
|  | 플레이어 피격 감지 | 공격 상태일 때 **몬스터의 공격 판정**과 **플레이어의 충돌을 감지** |
|  | 몬스터 피격 감지 | **플레이어의 공격 판정**과 **몬스터의 피격 판정**의 충돌을 감지 |
| 출력 | 상태 전환 | 입력 조건에 따라 몬스터의 AI 상태를 변경하고, 그에 맞는 애니메이션 ID를 재생 |
|  | 이동 처리 | 추격 상태일 때 플레이어 방향으로 몬스터를 회전 및 이동시킴 |
|  | 사망 처리(분열) | HP가 0이 되었을 때, 분열 횟수를 확인하여 **분열 로직** 또는 **완전 소멸 로직**을 실행 |
|  | 몬스터 생성 | **분열 로직** 실행 시, 지정된 개수만큼의 작은 쓰레기 봉지 몬스터 생성 |
|  | 피해 처리 | 플레이어 피격 감지 성공 시, 플레이어의 HP 감소 처리 |
|  | 데이터 저장 | 몬스터의 현재 HP 데이터를 관리하며, 0이 되면 사망 처리 |
