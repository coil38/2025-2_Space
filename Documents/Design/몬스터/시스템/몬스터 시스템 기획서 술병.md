# 몬스터 시스템 기획서 \- 술병

---

최신 업데이트 : 2025.10.07  
---

## 몬스터 개요

* 몬스터 이름 : 술병 (MOB\_Bottle)  
* 분류 : 일반 몬스터 (근접 돌진형)  
* 역할 : 플레이어의 위치 선정을 강제하고 회피 능력을 시험하는 기본적인 돌진 몬스터입니다.  
* 핵심 로직 : 플레이어를 인식하면 굴러서 추격하다가, 일정 거리 내에 접근하면 1초간의 명확한 준비 동작 후 정해진 거리만큼 빠르게 돌진하여 공격합니다.

## 행동 패턴

| 대기 (Idle) |  |
| :---- | :---- |
| 플레이어가 **인식 범위 밖에 있을 때 상태**입니다. MOB\_Bottle\_Idle 애니메이션을 반복 재생합니다. |  |
| 재생 시간 | 1.5초, 반복 |
| 전환 조건 | 플레이어가 인식 범위 안으로 들어오고, 공격 쿨다운이 아닐 경우 **추격(Move)상태로 전환**됩니다 |

| 추격 (Move) |  |
| :---- | :---- |
| 플레이어가 인식 범위 안에 있지만 돌진 준비 범위 밖에 있을 때의 상태. MOB\_Bottle\_Move 애니메이션(0.5초)을 반복 재생합니다. |  |
| 재생 시간 | 0.5초, 반복 |
| 전환 조건 1 | 플레이어가 **돌진 준비 범위** 안으로 들어오면 **공격 준비 상태로 전환**됩니다. |
| 전환 조건 2 | 플레이어가 **인식 범위** 밖으로 벗어나면 **대기 상태로 전환**됩니다. |

| 공격 준비 (Atk\_Ready) |  |
| :---- | :---- |
| 그 자리에서 이동을 멈추고 1초 동안 돌진을 준비합니다. MOB\_Bottle\_Atk\_Ready 애니메이션을 1회 재생합니다. 이 동안에는 방향을 바꾸지 않습니다. 해당 타이밍에 피격 범위 장판을 소환한다. |  |
| 재생 시간 | 1초, 1회 |
| 슈퍼 아머 상태 | 이 상태에서는 플레이어에게 피격당해도 경직 되지 않고 공격을 계속 준비합니다. |
| 전환 조건 | 애니메이션 재생이 끝나면, 플레이어가 있던 방향으로 **공격 상태로 전환**됩니다. |

| 공격 (Attack) |  |  |
| :---- | :---- | :---- |
| MOB\_Bottle\_Atk\_Start \-\> MOB\_Bottle\_Atk\_Loop \-\> MOB\_Bottle\_Atk\_End 해당 애니메이션을 순차적으로 재생합니다. Atk\_Loop 상태에서 돌진 거리만큼 빠르게 전진하며, **이 동안 닿는 플레이어에게 피해를 줍니다.** |  |  |
| 재생 시간 | MOB\_Bottle\_Atk\_Start | 0.08초, 1회 |
|  | MOB\_Bottle\_Atk\_Loop | 0.25초, 1회 |
|  | MOB\_Bottle\_Atk\_End | 0.17초, 1회 |
| 슈퍼 아머 상태 | 이 상태에서는 플레이어에게 피격당해도 경직 되지 않습니다. |  |
| 전환 조건 1 | 돌진 거리에 도달하거나, 벽에 부딪히거나, 플레이어에게 피해를 입히면 즉시 Atk\_End 애니메이션으로 전환된 후, 공격 쿨다운 동안 잠시 멈췄다가 **추격** 또는 **공격 준비 상태로 전환**됩니다. |  |
| 전환 조건 2 | 플레이어가 인식 범위 밖이라면 **대기 상태로 전환됩니다.** |  |

| 피격 (Hit) |  |
| :---- | :---- |
| '대기' 또는 '추격' 상태에서 플레이어에게 공격받았을 때의 상태입니다. MOB\_Bottle\_Hit 애니메이션을 재생하며 짧은 시간 동안 행동 불능이 됩니다. |  |
| 재생 시간 | 0.25초, 1회 |
| 시각 효과 | 피격 순간 몬스터의 2D 스프라이트가 **0.25초 동안 붉은색으로 점멸**하여 피격 사실을 명확하게 보여줍니다. |
| 전환 조건 | 애니메이션 재생이 끝나면 이전 상태로 돌아갑니다. |

| 사망 (Death) |  |
| :---- | :---- |
| 해당 몬스터의 체력이 HP \= 0일 때 상태입니다. MOB\_Bottle\_Death 애니메이션을 재생하며 종료 될 때 해당 몬스터를 제거합니다다. |  |
| 재생 시간 | 0.75초, 1회 |
| 사망 조건 | 몬스터의 HP \= 0 |

## 기능 요약

| 정의 | 근거리에서 예측 가능한 돌진 공격을 가하는 일반 몬스터 |
| :---- | :---- |
| 핵심 특징 | 명확한 1초의 선딜레이를 통해 플레이어에게 회피 타이밍을 제공 |
| 역할 | 플레이어의 움직임을 유도하고, 회피 컨트롤의 기본을 익히게 하는 역할 |
| 목표 | 플레이어에게 위험 예측과 대응이라는 게임의 기본 전투 공식을 학습시킴 |

## 시스템 구현

| 구분 | 항목 | 내용 |
| ----- | :---- | :---- |
| 입력 | 플레이어 감지 | 플레이어의 위치를 주기적으로 확인하여 **인식 범위** 및 **돌진 준비 범위** 내에 있는지 판단 |
|  | 플레이어 피격 감지 | 공격 상태일 때 **몬스터의 공격 판정**과 **플레이어의 충돌을 감지** |
|  | 몬스터 피격 감지 | **플레이어의 공격 판정**과 **몬스터의 피격 판정**의 충돌을 감지 |
| 출력 | 상태 전환 | 입력 조건에 따라 몬스터의 AI 상태를 변경하고, 그에 맞는 애니메이션 ID를 재생 |
|  | 이동 처리 | 추격 상태일 때 플레이어 방향으로 몬스터를 회전 및 이동시킴 |
|  | 돌진 처리 | 공격 상태일 때 고정된 방향으로 빠르게 몬스터를 이동시킴 |
|  | 피해 처리 | 플레이어 피격 감지 성공 시, 플레이어의 HP 감소 처리 |
|  | 데이터 저장 | 몬스터의 현재 HP 데이터를 관리하며, 0이 되면 사망 처리 |
