# 몬스터 시스템 기획서 \- 그루터기

---

최신 업데이트 : 2025.10.07  
---

## 몬스터 개요

* 몬스터 이름 : 그루터기 (MOB\_Stump)  
* 분류 : 일반 몬스터 (고정형, 지역 장악)  
* 역할 : 특정 위치에 지속적인 위협을 가하여 플레이어의 이동을 제한하고, 전투 지역을 불리하게 만드는 역할을 합니다.  
* 핵심 로직 : 생성된 위치에서 움직이지 않고, 플레이어의 위치를 조준하여 1초간 기를 모은 후 오염물질을 발사합니다. 발사된 투사체는 착탄 지점에 5초간 지속되는 피해 지역(장판)을 생성합니다.

## 행동 패턴

| 대기 (Idle) |  |
| :---- | :---- |
| **공격 쿨다운 상태**일 때의 기본 상태입니다. MOB\_Stump\_Idle 애니메이션을 반복 재생합니다. |  |
| 재생 시간 | 2초, 반복 |
| 전환 조건 | 공격 쿨다운이 아닐 경우, 즉시 **공격 준비 상태로 전환**됩니다. 플레이어가 맵에 있기만 하면 항상 공격을 시도합니다. |

| 공격 준비 (Atk\_Ready) |  |
| :---- | :---- |
| 1초 동안 공격을 준비합니다. 상태에 진입하는 순간의 플레이어 위치를 **목표 지점으로 고정**합니다. MOB\_Stump\_Atk\_Ready 애니메이션을 1회 재생합니다. |  |
| 재생 시간 | 1초, 반복 |
| 슈퍼 아머 상태 | 이 상태에서는 플레이어에게 피격당해도 경직 되지 않고 공격을 계속 준비합니다. |
| 전환 조건 | 애니메이션 재생이 끝나면 **공격 상태로 전환**됩니다. |

| 공격 (Attack) |  |  |
| :---- | :---- | :---- |
| MOB\_Stump\_Atk\_Start \-\> MOB\_Stump\_Atk\_End 애니메이션을 순차적으로 재생하며, **고정된 목표 지점**을 향해 오염물질 투사체를 생성하고 발사합니다. |  |  |
| 재생 시간 | MOB\_Stump\_Atk\_Start | 0.17초, 1회 |
|  | MOB\_Stump\_Atk\_End | 0.5초, 1회 |

| 피격 (Hit) |  |
| :---- | :---- |
| **대기상태**에서 플레이어에게 공격받았을 때의 상태입니다. MOB\_Stump\_Hit 애니메이션을 재생하며 짧은 시간 동안 행동 불능이 됩니다. |  |
| 재생 시간 | 0.33초, 1회 |
| 시각 효과 | 피격 순간 몬스터의 2D 스프라이트가 **0.25초 동안 붉은색으로 점멸**하여 피격 사실을 명확하게 보여줍니다. |
| 전환 조건 | 애니메이션 재생이 끝나면 이전 상태로 돌아갑니다. |

| 사망 (Death) |  |
| :---- | :---- |
| 해당 몬스터의 체력이 HP \= 0일 때 상태입니다. MOB\_Stump\_Death 애니메이션을 재생하며 종료 될 때 해당 몬스터를 제거합니다다. |  |
| 재생 시간 | 1.25초, 1회 |
| 사망 조건 | 몬스터의 HP \= 0 |

## 오염 지대 로직

| 생성 | 오염물질 투사체가 목표 지점에 도달하면 해당 위치에 오염 지대가 생성됩니다. 생성되는 순간 범위 내의 플레이어에게 초기 피격 피해를 줍니다. |  |
| :---- | :---- | :---- |
| 유지 | 오염 지대는 **5초간 유지**됩니다. 시각적으로 검은 웅덩이가 퍼져나갔다가 서서히 사라지는 이펙트가 출력됩니다. |  |
| 지속 피해 및 디버프 | 오염 지대 위에 있는 플레이어는 1초마다 **장판 틱 피해**를 받습니다. 피해를 받는 즉시, 플레이어는 **7초** 동안 **오염 디버프**에 걸립니다. |  |
|  | 오염 디버프 | 이동 속도가 50% 감소합니다. |
|  |  | 대시 쿨다운이 100% 증가합니다. |

## 기능 요약

| 정의 | 움직이지 않는 대신 원거리에서 지속 피해 장판을 생성하는 포대형 몬스터 |
| :---- | :---- |
| 핵심 특징 | 플레이어의 현재 위치가 아닌, '조준 시점'의 위치를 공격하여 플레이어의 예측 회피를 유도 |
| 역할 | 맵 전체에 걸쳐 지속적인 압박을 가하여, 플레이어가 끊임없이 움직이도록 강제. |
| 목표 | 플레이어가 단순히 적의 공격을 피하는 것을 넘어, 전장의 환경 변화에 능동적으로 대처하도록 학습시킴 |

## 시스템 구현

| 구분 | 항목 | 내용 |
| ----- | :---- | :---- |
| 입력 | 플레이어 감지 | 플레이어가 맵에 존재하는지 여부를 확인 **(상시 감지)** |
|  | 타이머 | 공격 쿨다운, 오염 지대 지속 시간, 플레이어 디버프 지속 시간 등을 계산 |
|  | 충돌 감지 | 오염 지대 영역과 플레이어의 충돌을 지속적으로 확인 |
|  | 몬스터 피격 감지 | 플레이어의 공격 판정과 몬스터의 피격 판정(Hurt Box)의 충돌을 감지 |
| 출력 | 상태 전환 | 입력 조건에 따라 몬스터의 AI 상태를 변경하고, 그에 맞는 애니메이션 ID를 재생 |
|  | 투사체 생성 | 공격 상태일 때 **오염물질 투사체 오브젝트를 생성**하고 **목표 지점으로 발사** |
|  | 오염 지대 생성 | 투사체가 목표 지점에 도달하면 **오염 지대 오브젝트(데미지 영역)를 생성** |
|  | 피해 및 디버프 처리 | 오염 지대 생성 순간 및 지속 시간 동안 플레이어의 HP를 감소시키고, **오염 디버프를 7초간 적용 및 갱신** |
|  | 데이터 저장 | 몬스터의 현재 HP 데이터를 관리하며, 0이 되면 사망 처리 |
