# 몬스터 시스템 기획서 \- 낡은 인형

---

최신 업데이트 : 2025.10.10  
---

## 몬스터 개요

* 몬스터 이름 : 낡은 인형 (MOB\_Doll)  
* 분류 : 엘리트 몬스터 (기회주의적 암살자형)  
* 역할 : 직접적인 위협은 적지만, 지속적으로 소환수를 생성하여 플레이어를 압박하고 전투를 복잡하게 만듭니다.  
* 핵심 로직 : 맵 전체를 인식 범위로 가지며, 주기적으로 **플레이어를 추격하는 실타래 3마리를 소환**합니다. 소환 후에는 다음 쿨다운까지 무작위로 맵을 배회합니다.

## 행동 패턴

| 대기 (Idle) |  |
| :---- | :---- |
| 배회가 끝났지만 아직 소환 쿨다운이 끝나지 않았을 때의 상태입니다. MOB\_Doll\_Idle 애니메이션을 반복 재생합니다. |  |
| 재생 시간 | 1.5초, 반복 |
| 전환 조건 | 소환 쿨다운이 종료되면 **소환 준비 상태로 전환**됩니다. |

| 배회 (Wander) |  |
| :---- | :---- |
| 소환을 마친 후, 소환 후 배회 시간 동안 맵의 무작위 지점으로 이동합니다. MOB\_Doll\_Move 애니메이션을 반복 재생합니다. |  |
| 재생 시간 | 1초, 반복 |
| 전환 조건 | 배회 시간'이 종료되면 **대기(Idle) 상태로 전환**됩니다. |

| 소환 준비 (Summon\_Ready) |  |
| :---- | :---- |
| 1.5초 동안 소환을 준비합니다. MOB\_Doll\_Summon\_Ready 애니메이션을 1회 재생합니다. |  |
| 재생 시간 | 1.5초, 1회 |
| 슈퍼 아머 상태 | 이 상태에서는 플레이어에게 피격당해도 경직 되지 않고 공격을 계속 준비합니다. |
| 전환 조건 | 애니메이션 재생이 끝나면 **소환(Summon) 상태로 전환**됩니다. |

| 소환 (Summon) |  |  |
| :---- | :---- | :---- |
| MOB\_Doll\_Summon\_Cast 와 MOB\_Doll\_Summon\_End 애니메이션을 순차적으로 재생하며, **실타래 3마리를 소환**합니다. |  |  |
| 재생 시간 | MOB\_Doll\_Summon\_Cast | 0.5초, 1회 |
|  | Doll\_Summon\_End | 0.5초, 1회 |
| 슈퍼 아머 상태 | 이 상태에서는 플레이어에게 피격당해도 경직 되지 않습니다. |  |
| 전환 조건 | 돌진 거리에 도달하거나 벽에 부딪히면 즉시 **도망(Run) 상태로 전환**됩니다.. |  |

| 피격 (Hit) |  |
| :---- | :---- |
| **대기상태**에서 플레이어에게 공격받았을 때의 상태입니다. 피격 시 몬스터 몸 주변으로 작은 쓰레기가 떨어져 나옵니다. 오직 시각 효과입니다. MOB\_TBag\_Hit 애니메이션을 재생하며 짧은 시간 동안 행동 불능이 됩니다. |  |
| 재생 시간 | 0.33초, 1회 |
| 시각 효과 | 피격 순간 몬스터의 2D 스프라이트가 **0.25초 동안 붉은색으로 점멸**하여 피격 사실을 명확하게 보여줍니다. |
| 전환 조건 | 애니메이션 재생이 끝나면 이전 상태로 돌아갑니다. |

| 사망 (Death) |  |
| :---- | :---- |
| 해당 몬스터의 체력이 HP \= 0일 때 상태입니다. MOB\_MiniP\_Death 애니메이션을 재생하며 종료 될 때 해당 몬스터를 제거합니다. |  |
| 재생 시간 | 1.25초, 1회 |
| 사망 조건 | 몬스터의 HP \= 0 |

## 소환수 실타래 로직

| 소환 | 낡은 인형'은 한 번에 3마리의 실타래를 소환합니다. |  |
| :---- | :---- | ----- |
| 붉은 실타래 | 소환되는 각 실타래는 **25%의 확률**로 붉은 실타래가 됩니다. |  |
|  |  붉은 실타래는 일반 실타래보다 2배의 피해를 줍니다. |  |
| 추격 | 소환된 모든 실타래는 즉시 플레이어를 향해 굴러가며 추격합니다 |  |
| 공격 | 실타래는 별도의 공격 모션 없이, 플레이어와 충돌하는 즉시 피해를 주고 자신은 파괴됩니다. (자폭형) |  |
| 파괴 | 플레이어는 실타래를 직접 공격하여 체력을 0으로 만들어 파괴할 수 있습니다. |  |

## 기능 요약

| 정의 | 주기적으로 자폭형 소환수를 생성하고, 자신은 안전한 위치로 이동하는 엘리트 몬스터 |
| :---- | :---- |
| 핵심 특징 | 직접 공격 대신 실타래를 소환하여 다대일 전투 구도를 형성. 소환수 중 일부는 강화된 '붉은 실타래'로 생성됨 |
| 역할 | 플레이어에게 다수의 목표를 동시에 관리하고 위협적인 대상을 먼저 처리하는 타겟 우선순위 판단을 강제 |
| 목표 | 플레이어가 복잡한 전투 상황에 적응하고, 주요 위협원(소환사)을 먼저 제거하는 전략적 플레이를 학습하도록 유도 |

## 시스템 구현

| 구분 | 항목 | 내용 |
| ----- | :---- | :---- |
| 입력 | 플레이어 감지 | 플레이어가 맵에 존재하는지 여부를 확인 **(상시 감지)** |
|  | 몬스터 피격 감지 | 플레이어의 공격 판정과 낡은 인형의 피격 판정 충돌을 감지 |
|  | 소환수 피격 감지 | 플레이어의 공격 판정과 실타래의 피격 판정 충돌을 감지 |
|  | 소환수 충돌 감지 | 실타래와 플레이어의 충돌을 감지 (공격 판정) |
|  | 타이머 | 소환 쿨다운과 소환 후 배회 시간을 계산 |
| 출력 | 상태 전환 | 타이머 조건에 따라 **낡은 인형**의 AI 상태(대기, 배회, 소환)를 변경 |
|  | 이동/돌진/도망 처리 | 각 상태에 맞는 속도와 방향으로 몬스터를 이동시킴 |
|  | 소환수 생성 | 소환 상태일 때 실타래 오브젝트 3개를 생성. 각 소환 시 25% 확률로 붉은 실타래 버전으로 생성하는 로직 포함. |
|  | 무작위 이동 처리 | 배회 상태일 때, 맵 내 이동 가능한 무작위 좌표를 계산하고 해당 위치로 이동 |
|  | 피해 처리 | 소환수 충돌 감지 성공 시, 실타래의 종류에 따라 플레이어 HP 감소 처리 |
|  | 데이터 저장 | 낡은 인형 본체와 생성된 모든 실타래 개체의 HP를 각각 관리.  0이 되면 사망 및 파괴 처리. |
