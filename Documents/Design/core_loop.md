# 게임 기본 루프(Core Loop) 설계
## 개요
본 문서는 로그라이크 액션 게임의 핵심 재미 순환 구조인 **코어 루프(Core Loop)**와 플레이어가 장기적으로 게임에 몰입하게 만드는 **확장 루프(Expansion Loop)**  및 **메타 루프(Meta Loop)**를 정의한다.
## 코어 루프 (Core Loop)
플레이어가 게임의 한판 내에서 가장 반복적으로 경험하는 핵심적인 재미의 순확 구조이다.
- 한줄요약 : 몬스터와 전투하여 경험치와 유물을 얻고, 이를 통해 성장하여 다음 전투를 유리하게 이끈다.
- 코어 루프 다이어그램 : 
  - [전투] -> [경험치/유물 획득] -> [레벨업] -> [유물 장착 중략 증가/스킬 해금] -> [전투]
## 루프 단계별 상세 설명
A. 행동(Action) : 플레이어는 무엇을 하는가?
- 행동 : 몬스터와 전투한다.
- 상세 내용 : 스테이지에 존재하는 방에 진입하여 몬스터를 만난다. 스킬과 평타를 이용하여 몬스터를 처치한다. 이과정에서 플레이어는 컨트롤의 재미와 몬스터의 행동 패턴을 학습한다.
B. 보상(Reward) : 행동의 경과로 무엇을 얻는가?
- 보상 : 경험치(EXP), 아이템(유물)을 획득한다.
- 상세 내용 : 몬스터를 처치하면 즉각적으로 수치화된 보상(경험치)과 확률적으로 눈에 보이는 보상(유물)이 주어진다. 좋은 유물을 획득했을 때의 만족감이 크다.
C. 확장 루프 (Expansion Loop)
코어 루프가 여러 번 반복되며 한 판의 플레이를 완성시키는 더 큰 루프이다. 플레이어의 선택과 목표를 제시하는 역할을 한다.
- 루프 다이어그램:
  - [스테이지 선택] -> [스테이지 탐험(코어 루프 반복)] -> [중간 보스 처치] -> [스테이지 선택] -> ... -> [최종 보스 처치]
- 상세 설명:
    - 스테이지 선택 : 플레이어는 제시된 루트(스테이지) 중 하나를 전략적으로 선택한다. 한번 선택한 루트는 되돌릴 수 없으므로 신중한 경정이 요구된다.
    - 스테이지 탐험 : 선택한 스테이지에 진입하여 코어 루프를 반복하며 캐릭터를 성장 시키고 다음 스테이지로 나아간다.
    - 보스 조우 및 처리 : 일정 스테이지 구간 다음에 등장하는 중간 보스 또는 최종 보스를 만난다. 해당 판에서 성장시킨 결과를 증명하는 시험대 역할을 한다.
    - 루프의 반복 : 보스를 처치하면 새로운 스테이지 선택지가 나타나며, 최족 보스를 깰 때까지 이과정을 반복한다.
  ## 메타 루프 (Meta Loop)
  로그라이크 장르의 핵심. 한 판의 플레이가 성공 또는 실패로 끝난 뒤에도 플레이어가 게임을 다시 시작하도록 만드는 가장 큰 규모의 동기 부여 루프이다.
  - 루프 다이어 그램:
    - [게임 플레이(확장 루프 반복)] -> [죽음 또는 클리어] -> [업적 달성] -> [영구 능력치 강화/신규 캐릭터, 유물 해금] -> (더 나은 조건으로 다시)[게임 플레이]
  - 상세 설명:
    - 죽음의 가치 : 이 게임에서 죽음은 완전한 실패가 아니다. 플레이 과정에서 얻은 업적을 통해 영구적인 성장을 이룰 수 있다.
    - 영구 성장 : 매판 초기화되는 능력치와 별개로, 게임을 반복 플레이하며 얻은 시작 능력치 강화, 새로운 직업 해금 등을 할 수 있다.
    - 재도전 동기 부여 : "이번판엔 더 강한 상태로 시작하니 더 멀리 갈 수 있을거야!"라는 기대감을 싱어주어, 실패에 대한 좌절감을 줄이고 즉각적인 재도전 욕구를 자극한다.
