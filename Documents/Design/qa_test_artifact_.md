# 일반/엘리트 몬스터 밸런스 테스트
1. 테스트 분류
-유물 밸런스 / 아이템 시스템
2. 기획 의도
- 플레이어의 공격력을 상승하는 유물이다.
- 적은량의 오염도 수치(중량)으로 장착이 가능하다.
- 초반에 유용하게 사용 할 수 있도록 설게되어 있다.
3. 핵심 수치 (기획값)
- 유물 이름 : 소형 공격 연산기
- 분류 : 오염된 프로세스
- 오염도 수치 : 10
- 효과 : 공격력 8%상승
4. QA 검증 기준
- TC 1 : 공격력 증가
  - 공격력이 상승 여부
- TC 2 : 유물 장착 할 경우
  - 유물을 장착시 즉시 효과 적용
  - HUD에 아이콘 적용
  - 오염도 게이지 증가
- TC 3 : 유물 해제 할 경우
  - 유물을 해제할 경우 즉시 효과 해제
  - HUD에 아이콘 제거
  - 오염도 게이지 감소
5. 예상 결과
- TC 1 결과 : 플레이어의 데미지 상승
- TC 2 결과:
  - 유물 효과 적용
  - HUD에 유물칸에 아이콘 적용
  - 오염도 게이지 증가
- TC 3 결과:
  - 유물 효과 해제
  - HUD에 유물칸에서 아이콘 제거
  - 오염도 게이지 감소
