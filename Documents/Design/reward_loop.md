# 보상 및 경계 루프 설계
유물 및 경험치 시스템 기반의 통한 루프 분석
- 문서 버전 : 0.0.1
- 문서 업데이트 : 2025.10.20
## 개요
본 문서는 '프로세스(유물) 시스템'과 '경험치 시스템'을 기반으로, 플레이어가 게임에 지속적으로 몰입하고 장기적인 목표를 설정하게 만드는 통합적인 보상 및 경제 루프를 분석하고 설계하는 것을 목적으로 한다.
## 이중 성장 루프
본 세임의 성장 루프는 크게 **유물 성장 루프**와 **캐릭터 성장 루프**라는 두개의 축으로 구성된다. 이 두 루프는 서로 유기적으로 연결되어 시너지를 발생시킨다.
### 유물 성장 루프 : 파밍 -> 관리 -> 정화 -> 강화
한 판의 플레이 내에서 아이템 조합을 통해 강해지는 루프
- [1단계: 파밍] : 몬스터와 상자를 통해 '오염도 프로세스'를 획득한다.
- [2단계: 관리] : '오염도 게이지' 한계 내에서 최적의 유물 조합을 고민하고 선택한다.
- [3단계: 정화] : '리스크 효과'유물을 '정화기'로 변환하여 중략 없는 강력한 유물을 획득한다.
- [4단계: 강화] : 보스 처치, 히든 상자 탐색 등 상위 콘텐츠에 도전하여 가장 희귀한 '근원 프로세스'를 획득한다.
### 캐릭터 성장 루프 : 사냥 -> 경험치 획득 -> 레벨업 -> 성장
플레이어 캐릭터 자체가 영구적으로 강해지는 루프
- [1단계 : 사냥 및 탐험] : 몬스터를 처치, 스테이지 보상 상자를 여는 등, 유물 파밍과 동일한 행동을 수행한다.
- [2단계 : 경험치 획득] : 모든 보상 활동에서 유물과 함께 경험치(EXP)를 꾸준히 획득한다.
- [3단계 : 레벨업] : 누적된 경험치로 레벨이 상승한다.
- [4단계 : 성장] : 레벨업 보상으로 기본 스탯(공격력, 체력)이 상승하고, '오염도 게이지'가 확장되며, 특정 레벨마다 강력한 스킬이 해금된다.
## 통합 루프의 시너지
두 성장 루프는 다음과 같이 서로 강화하며 긍정적인 피드백 루프를 형성한다. 
- [사냥/탐험] -> 1.유물 획득 & 2.경험치 획득 -> [레벨업] -> 3.오염도 게이지 확장 -> 4.더 많은 유물 장착 가능 -> [캐릭터 강화] -> (더 쉬워진)[사냥/탐험]
1. 시작점 : 플레이어의 모든 핵심 활동(사냥, 탐험)은 두 성장 루프의 재화(유물, 경험치)를 동시에 제공한다.
2. 캐릭터 성장 : 획득한 경험치로 레벨업하면, 캐릭터의 기본 스펙이 강해질 뿐만 아니라 '오염도 게이지'가 확장된다.
3. 유물 성장 촉진 : 확장된 '오염도 게이지'는 '관리'단계의 제약을 완화시켜, 플레이어가 더 많거나 강력한 '오염된 프로세스'를 장착할 수 있게 해준다.
4. 피드백 강화 : 더 강력한 유물 조합을 갖춘 플레이어는 더 어려운 콘텐츠에 도전하여 더 좋은 유물과 더 많은 경험치를 얻을 수 있게 되며, 이 순환이 반복된다.
