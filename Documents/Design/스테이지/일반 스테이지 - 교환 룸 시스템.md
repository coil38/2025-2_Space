# 일반 스테이지 \- 교환 룸 시스템

---

최신 업데이트 : 2025.11.08  
---

## 시스템 개요

교환기 룸은 일반 스테이지의 비전투 이벤트 구간으로, 스테이지 생성 시 **10%확률**로 등장합니다. 한 스테이지에서 **최대 1회**만 등장할 수 있습니다.  
이 룸의 핵심 기능은 플레이어가 보유한 **\[오염된 프로세스\]를 소모**하여, **다른 종류의 \[오염된 프로세스\]** 확률에 따라 0개, 1개, 2개 획득하는 **도박성 이벤트**입니다.  
몬스터가 스폰되지 않는 안전 구역이며, 룸의 입/출구는 항상 열려있습니다.  
룸 중앙에는 **상호작용이 가능한 교환기 오브젝트**가 배치됩니다.

## 주요 기능

* 비전투 안적구역 (몬스터 스폰 x)  
* 입출구 문 상시 개방  
* 핵심 기능 : \[오염된 프로세스\] 1개 소모 시, 확률에 따라 결과 변동  
  * 80%(성공) : 다른 종류의 오염된 프로세스 1개 획득  
  * 20%(대성공) : 다른 종류의 오염된 프로세스 2개 획득  
  * 10%(실패) : 투입한 유물 파괴 (0개 획득)  
* 사용 횟수 : 교환기 오브젝트 당 최대 5회 사용 가능

## 상세 설명

### 정화기 룸이란?

일반 스테이지에서 10% 확률로 등장하는 특별한 이벤트 룸입니다.플레이어에게 현재 빌드에 필요 없거나 중복되는 오염된 프로세스를 다른 유물로 바꿀 수 있는 기회를 제공하는 것을 목적으로 합니다.  
stage\_design\_normal.md의 규칙에 따라, 다른 비전투 룸(교환기, 보급 상자 룸)과 연속으로 배치될 수 없습니다.

### 교환이란?

플레이어가 보유한 오염된 프로세스 중 하나를 선택하여 교환기에 넣는 과정입니다. 교환기는 투입된 유물을 소모하며, 확률적 결과를 변환합니다.

* 70%(성공) : 투입된 유물을 소모하여 오염된 프로세스 1개 획득  
* 20%(대성공) : 투입된 유물을 소모하여 오염된 프로세스 2개 획득  
* 10%(파괴) : 투입한 유물을 소모하여 아무것도 획득 불가

### 오브젝트 컨셉

파괴된 우주선 잔해 근처에 알 수 없는 고대 기술의 교환기가 작동하고 있는 신비로운 분위기의 룸입니다.

## 정화기 룸과 상호작용

일반 스테이지 ⊃ 교환기 룸 ⊃ 교환기 오브젝트의 관계를 가집니다.

| 구분 | 설명 |
| :---- | :---- |
| 정화기 룸 | **설명** : 일반 스테이지의 룸 중 하나. 10%확률로 등장(최대 1회) 비전투 안전 구역 **보상** : 오염된 프로세스를 교환할 기회 |
| 정화기 오브젝트 | **설명** : 룸 중앙에 배치된 상호작용 오브젝트 **보상** : 상호작용(F)시 정화 UI가 열리며, 최대 5회까지 유물 교환 가능 |

## 시스템 구현

| 구분 | 항목 | 내용 |
| ----- | :---- | :---- |
| 입력 | 룸 입장 트리거 | 플레이어가 룸 입장 경계 통과 시 자동 감지 |
|  | 정화기 상호작용 | 상호작용(F) 키로 교환기 오브젝트와 상호작용 |
|  | UI 입력 | 정화 UI 내에서 교환할 유물 선택 및 교환 버튼 클릭 |
| 출력 | 문 상태 | 입/출구 문이 항상 개방 상태로 유지됨 |
|  | 정화기 룸 씬 | 교환기 씬 등장 |
|  | 정화 UI | 상호작용 시 정화 UI 활성화. (플레이어가 보유한 '오염된 프로세스' 목록 표시) |
|  | 교환 결과 이펙트 | 교환 결과(성공/대성공/파괴)에 따라 각기 다른 시각/청각/이펙트 출력 |
|  | 오브젝트 파괴 | 사용 횟수 5회 소진 시, 교환기 오브젝트가 파괴되는 이펙트/사운드 출력 |

## 단계별 상세 설명

| 단계 | 설명 |
| :---- | :---- |
| 룸 진입 | 룸 진입. 문이 열려있고 몬스터가 없는 것을 인지 |
| 오브젝트 발견 | 룸 중앙에 있는 교환기와 파괴된 우주선 잔해 발견 |
| 상호작용 | 플레이어가 교환기에 접근하여 상호작용(F)키 입력 |
| UI사용 | 교환 UI가 출력 됨 |
| 유물 선택 및 정화 | 플레이어가 교환할 오염된 프로세스를 선택하고 교환 버튼 클릭 |
| 변환 확인 | 선택한 유물이 인벤토리에서 사라짐. 확률 판정에 따라 0개(파괴), 1개(교환), 또는 2개(대성공)의 유물이 획득됨. |
| 횟수 차감 / 파괴 | 정화기 사용 횟수가 1회 차감됨 모두 사용 시 교환기 오브젝트 파괴 |
| 다음 룸으로 이동 | 플레이어가 볼일 마친 후 열려있는 출구를 통해 다음 룸으로 이동 |

## 예외 처리

* 교환할 유물 없음 : 플레이어가 리스크 유물이 하나도 없을 경우, 상호작용 시 “교환할 수 있는 오염된 프로세스가 없습니다.” 알림 메시지를 출력하고 UI가 열리지 않습니다.  
* 연속 배치 오류 : stage\_design\_normal.md의 규칙에 따라, 이 룸 이전에 비전투 룸(정화기, 보급 상자 룸)이 있었다면 이 룸을 생성하지 않고 일반 전투 룸으로 자동 대체합니다.  
* 최대 횟수 초과 : 스테이지 내에 이미 정화기 룸이 1회 생성 되었다면, 남은 룸 생성 시도 시 정화기 룸을 후보에서 제외합니다.
