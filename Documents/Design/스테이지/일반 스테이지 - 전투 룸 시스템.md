# 일반 스테이지 \- 전투 룸 시스템

---

최신 업데이트 : 2025.11.06  
---

## 시스템 개요

전투 룸은 일반 스테이지의 핵심 전투 구간으로, 스테이지 생성 시 60%의 확률로 등장합니다.  
각 룸은 입장 시 입출구가 잠기며, 룸 내 모든 몬스터 웨이브(1\~2회)를 처치하여야만 문이 열려 다음 방으로 진입할 수 있습니다.  
몬스터 처치 시 개별 보상을 드랍하며, 엘리트 몬스터 룸의 경우 20% 확률로 히든 상자라는 추가 보상을 지급합니다.

## 주요 기능

* 룸 입장 시 입/출구 문 자동 봉쇄  
* 룸 클리어시 문 자동 해제  
* 몬스터 웨이브 (1\~2회) 기반의 전투 진행  
* 일반 몬스터 드랍 : enemy\_balance.json 및 reward.json 참조  
* 엘리트 룸 클리어 시 : 20% 확률로 **히든 상자 스폰**

## 설명

### 전투 룸이란?

**일반 스테이지**에서 가장 높은 비중으로 등장하는 룸 타입입니다.  
플레이어의 전투 능력을 시험하고 성장의 핵심 재화(경험치, 유물)를 공급하는 것을 주 목적으로 합니다.  
**정화기**, **교환기** 등 다른 상호작용 오브젝트는 존재하지 않습니다. (단, '필드 공격 룸'의 경우 환경 기믹이 존재합니다.)

### 룸의 하위 타입

전투 룸은 진입시 stage\_design\_normal.md에 정의된 확률과 최대 등장 횟수(스테이지 당) 제한에 따라 다음 4가지 세부 타입 중 하나로 결정됩니다.

* 일반 전투 룸 (50%)  
* 필드 공격 룸 (20%)  
* 지정 몬스터 룸 (20%)  
* 엘리트 몬스터 룸 (10%)

### 몬스터 웨이브란?

룸을 클리어하기 위해 처치해야 하는 몬스터의 묶음(그룹)입니다. 각 룸의 세부 타입에 따라 1\~2회의 몬스터 웨이브가 순차적으로 등장하며, 현재 웨이브의 모든 몬스터를 처치해야 다음 웨이브가 진행됩니다.

## 전투 스테이지와 룸과 몬스터 웨이브

일반 스테이지 ⊃ 전투 룸 ⊃ 몬스터 웨이브의 관계를 가집니다.

| 구분 | 설명 |
| :---- | :---- |
| 전투 룸(상위) | **설명** : 일반 스테이지의 룸 중 하나 60% 확률로 등장. 4가지 세부 타입 존재 **보상**  : 몬스터 개별 드랍. 단, 엘리트 룸의 경우 20% 확률로 히든 상자 추가 보상 |
| 세부 타입 (4종 타입) | **설명** : 룸 진입 시 결정되는 룸 상세 규칙. 몬스터 종류, 웨이브 횟수, 필드 기믹이 결정됩니다. **보상** : 몬스터 개별 드랍. 단, 엘리트 룸의 경우 20% 확률로 히든 상자 추가 보상 |
| 몬스터 웨이브 | **구간** : 룸에 소속된 스폰 시스템. 1\~2회 웨이브가 발생하며 한 웨이브의 몬든 몬스터를 처치해야 다음 웨이브가 진행 또는 룸 클리어 **보상** : 몬스터 개별 드랍. 단, 엘리트 룸의 경우 20% 확률로 히든 상자 추가 보상 |

## 시스템 구현

| 구분 | 항목 | 내용 |
| ----- | :---- | :---- |
| 입력 | 룸 입장 트리거 | 플레이어가 룸 입장 경계 통과 시 자동 감지 |
|  | 전투 판정 | 룸 컨트롤러가 남은 몬스터 수를 카운트 |
|  | (특수) 히든 상자 | (엘리트 룸 클리어시) 상호작용(F) 키로 보상 획득 |
| 출력 | 문 잠금 / 해제 | 진입 시 봉쇄, 클리어 시 자동 해제 |
|  | 몬스터 스폰 | 웨이브 단위로 적 스폰 |
|  | 필드 기믹 | 5초 마다 6개의 자판기 캔 드랍 |
|  | 히든 상자 등장 | (엘리트 룸 전용) 클리어 시 20% 확률로 히든 상자 스폰 |
|  | 몬스터 드랍 | reward.json 참조 |

## 단계별 상세 설명

| 단계 | 설명 |
| :---- | :---- |
| 룸 진입 | 트리거 감지 후 문 잠김 \+ 몬스터 소환 시작 |
| 전투 | 웨이브 시작. 몬스터 스폰(필드 공격 룸의 경우 캔 드랍 시작) |
| 웨이브 클리어 | 첫 웨이브 몬스터 전멸 \-\> (다음 웨이브 존재 시) 1.5\~3초 후 다음 웨이브 스폰 |
| 룸 클리어 | 마미작 웨이브의 모든 몬스터 처치 \-\> 필드 기믹 정지 \-\> 출구 열림 |
| (특수) 보상 | (엘리트 룸일 경우) 20% 확률로 히든 상자 스폰 |
| 다음 룸으로 이동 | 플레이어가 보상 획득 후 다음 룸으로 이동 |

## 예외 처리

* 몹 스폰 오류 \-\> 예비 스폰 호출  
* 플레이어 사망 \-\> 스폰 정지, 게임 오버 UI창 활성화  
* 몬스터 스폰은 문 닫힌 후 실행  
* 최대 횟수 초과 \-\> 남은 횟수인 타입 중 1개로 대체
