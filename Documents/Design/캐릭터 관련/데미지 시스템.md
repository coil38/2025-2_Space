# 데미지 시스템

---

최신 업데이트 : 2025.09.02  
---

## 시스템 개요

 데미지 시스템은 플레이어가 몬스터에게 가하는 공격력을 계산하는 핵심 로직이다.  
본 게임에서는 방어력, 방어 무시 등의 요소는 존재하지 않으며, 공격자의 능력치와 보정 요소(코어, 오염된 프로세스, 치명타 등)에 의해 최종 피해량이 산출된다.

## 주요 기능

* 기본 공격/스킬의 데미지 산출  
* 코어 레벨 상승 및 오염된 프로세스에 따른 능력치 보정 반영  
* 스킬별 데미지 배율 적용  
* 피해량 증가(패시브/오염된 프로세스 효과/칭호 효과 등) 적용  
* 치명타 판정 및 데미지 보정

## 데미지 종류

| 종류 | 효과 종류 | 설명 |
| :---- | :---- | :---- |
| 기본 공격력 | 캐릭터 고유 공격력 업적 보상 효과 등등 | 플레이어가 기본적으로 가지고있는 기본적인 공격력 칭호 효과 또는 업적을 통해 높일 수 있다. |
| 스킬 데미지 배율 | 칩셋 스킬 고유 배율 업적 보상 효과 등등 | 칩셋 스킬들에 부여된 고유적인 데미지 배율 칩셋 스킬들 마다의 데미지 배율은 각각 다르다. 평타 또한 배율을 가지고 있다. |
| 공격력 증가 | 오염된 프로세스 칭호 코어 레벨 효과 등등 | 기본 공격력의 데미지를 증가 시키는 효과 오염된 프로세스(유물), 칭호, 코어 레벨에 의해 증가시킬 수 있다. 피해 데미지 증가와는 같이 계산을 안한다. |
| 피해 데미지 증가 | 오염된 프로세스 칭호 등등 | 치명타 데미지를 제외한 최종 공격력의 데미지를 증가 시킨다. 공격력 증가와는 같이 계산을 안한다. |
| 치명타 데미지 | 오염된 프로세스 칭호 스킬 고유 효과 등등 | 피해 데미지를 곱한 이후 최종 데미지의 데미지를 증가 시킨다. |

## 피해 데미지 종류

| 종류 | 내용 |
| :---- | :---- |
| 모든 피해 데미지 증가 | 모든 피해 데미지를 증가하는 효과이다. 예: 데미지 줄 시 효과 획득  |
| 특정 스킬 데미지 증가 | 특정 스킬을 사용했을때만 피해 데미지 증가 효과를 볼 수 있다. 예: 특정 스킬 사용 시 스킬 1 : 사용할 시 효과 획득 |

## 데미지 공식 설명

| 데미지 공식 설명 |  |
| :---- | :---- |
| 데미지 공식 |  |
| 최종 데미지 | {기본 데미지 x (100 \+ 공격력 증가 \+ 공격력 감소)/100} x 스킬 데미지 배율 x {(100 \+ 피해 데미지 증가)/100} x {(100 \+ 치명타 데미지)/100} |
| 단게별 설명 |  |
| 기본 데미지 산출 | 캐릭터가 보유한 기본 공격력 수치 예 : 기본 공격력 \= 20 |
| 능력치 보정 (코어 \+ 오염된 프로세스 \+ 칭호 효과 등) | 코어 레벨 효과 : 공격력 % 증가 예: \+15% 칭호 효과 : 공격력 % 증가 예: \+10% 오염된 프로세스 효과 : 공격력 % 증가 예: \+10% 오염된 프로세스 효과 : 공격력 % 감소 예 : \-5% 계산식 : (100 \+ 15 \+ 10 \+ 10 \- 5\) / 100 \= 1.3배 |
| 스킬 데미지 비율 적용 | 스킬 고유 배율 예: 스킬 1 \= 1.5배 스킬 2 \= 2.0배 평타 배율 1.0로 처리 |
| 피해 증가 효과 적용 | 특정 유물/버프 효과에 의한 피해 증가 예: 피해 데미지 증가 : \+20% 검사 칩셋 피해 데미지 증가 : \+20% |
| 치명타 보정 | 치명타 확률 판정 후, 치명타 발생 시 보정 치명타 데미지 \= 100% \+ 추가 배율 예: \+50% \-\> 총 150% |
| 예시 계산 |  |
| 기본 데미지 : 20 기본 치명타 데미지 증가 : 50% 코어 레벨 효과: 공격력 : \+ 15% 오염된 프로세스 효과: 공격력 : \+15% 피해 데미지 : \+10% 공격력 : \-10% 스킬 배율 : 1.5 칭호 효과: 피해 데미지 : \+20% 스킬 고유 효과: 치명타 데미지 : \+50% 공격력 : \-25% | {20 x (100 \+ 15 \+ 15 \- 10 \- 25)/100} x 1.5 x {(100 \+ 10 \+ 20)/100} x {(100 \+ 100)/100} \= 74.1 |

## 참고 사항

* 방어력, 방어 무시는 본 게임 시스템에서 제외된다.  
* 치명타는 확률 판정에 의해 발동되며, 기본 확률 \+ 오염된 프로세스/코어/버프 효과를 합산하여 계산한다.  
* 피해 증가 효과는 모든 피해 증가, 특정 스킬 피해 증가 등 세부적으로 분배가 된다.
